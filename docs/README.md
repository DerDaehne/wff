# WFF Docs

Die verbindliche Wissensbasis (Zettelkasten) liegt im **kabai**-System, nicht
in diesem Ordner. Einstieg über den Hub `wff-hub`.

Zentrale Notes:

- `wff-hub` — Übersicht / Einstiegspunkt
- `adr-001-wff-tech-stack` — Tech-Stack-Entscheidung (Go, PostgreSQL, SvelteKit-PWA, Nix/Docker)
- `arch-wff-overview` — Architektur-Überblick (Ingestion → Storage → Enrichment → Analyse → Präsentation)

Weitere Notes entstehen pro Child-Epic (Datenmodell/Schema, Metrik-Formeln,
Enrichment, Auth). Architektur-/Design-/Schema-Entscheidungen werden dort
dokumentiert (nicht in diesem Ordner), damit sie versioniert und verlinkt sind.
